# Didavero 0.7.0-beta.2

This preview improves editing, export and teaching-programme generation. Back up projects before updating. Existing Didavero and Apuntes IA data paths remain compatible.

## Changes

- Note saves run in order, retain pending status for newer edits and flush before export. Failed saves prevent section changes; manual retry is available.
- Exam export waits for preview/printing options to reach disk. Failed option saves retain the local preview and offer a retry.
- Programme research and authoring cannot overlap for the same purpose. New proposals capture research/context snapshots and reject stale application.
- Invalid full-programme results cannot replace a saved draft when units are absent, hours do not add up, researched sections are blank or an explicit minimum unit count is missed.
- Generation cannot populate previously empty requirements when research documents none. Coverage gaps remain visible for teacher review.
- Consolidated maintenance, security, context and performance guides replace obsolete planning documents and the retired website source.
- Updated compatible security dependencies and adapted legacy packaging imports to the patched matcher API, with explicit ASAR/filter regressions and the existing audit gate retained.

## Validation and scope

Local TypeScript checking, production builds and all 164 tests passed. Programme integration also exercises a subprocess CLI fixture through the real queue, including rejection that preserves the previous state file byte for byte. These synthetic checks do not qualify live model content, legal compliance or pedagogical quality.

Platform CI results and published artifacts are recorded in the GitHub release. Unsigned packages use manual downloads; this preview does not establish signed-update or cross-platform runtime qualification. No additional model review loop is introduced.
