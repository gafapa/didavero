# Didavero website and product rename

The public site is generated by `npm run build:site` from `website/` into `output/didavero-site/`. It contains Spanish and English landing pages plus legal notice, privacy, cookies/storage, AI transparency, usage terms, contact and accessibility pages. Assets, fonts and screenshots are self-hosted. No browser analytics, cookies, persistent browser storage, embedded third-party content or runtime release API requests are included. The infrastructure still produces access logs and internal anonymised reports, disclosed separately in the privacy notice.

The operator supplied and authorised the public identity in `website/site.config.json`. Hosting was checked against s1: Oracle Cloud `eu-frankfurt-1`, shared Nginx/Traefik static hosting, daily or 100 MB log rotation with 30 rotated files plus the active file. The existing mail mode was inspected independently; a working public contact route must be confirmed before launch.

## Downloads

Didavero `0.7.0-beta.1` is a new Windows x64 portable preview built locally with electron-builder. The file, size and SHA-256 in `site.config.json` are checked during site generation and verification; a different artifact cannot silently replace it. The build copies the approved file from the approved artifact path in the site configuration into the public download directory and emits its checksum sidecar. A fresh checkout needs that approved artifact before building the production website. `node scripts/verify-site.mjs` validates all local page links, legal routes, restrictive content policy, absence of unexpected browser tracking code and the download checksum.

The public GitHub release `v0.6.0` predates the current curriculum/programme work. Its older Apuntes IA installers remain available under an explicitly labelled older-release section. The site does not represent those assets as containing every feature shown in the preview. It does not claim signed installers, macOS/Linux qualification of the preview, guaranteed model availability or administrative certification.

## Rename compatibility

Visible product labels, window title, package metadata, shortcuts and future installer names use Didavero. The GitHub repository and local origin are `gafapa/didavero`. The established application ID, backup manifest filename and environment-variable names remain stable for compatibility. `electron/storagePaths.ts` uses existing Apuntes IA settings/data and portable directories when present; new installations default to Didavero. No user files are moved or deleted by the rename. A regression covers installed, portable and fresh paths.

## Legal scope

The website texts describe the actual data flows and intended teaching-material authoring use. They do not certify GDPR or AI Act conformity. The documentation separates the website operator, local institutional data controller and independently configured AI providers. It describes possible external processing and transfers rather than claiming offline-only or automatically encrypted operation. AI limitations, human review, literacy, incident reporting and exclusions from learner grading/admissions/proctoring are documented. In particular, machine-readable AI output marking is not claimed as implemented for every export: Article 50 applicability and the provider/integrator role remain technical/legal assessment work for the product, not an obligation discharged by a web page.

Before using real learner data, an institution must determine its legal basis, processor contracts, transfers, access/retention rules and any required impact assessment. The operator must maintain the actual processing register, rights/incident handling, provider agreements and retention measures; website notices alone are insufficient. The declared MIT licence is now included as `LICENSE` and made available on the site.

Sources reviewed on 2026-10-20: [LSSI](https://www.boe.es/buscar/act.php?id=BOE-A-2002-13758), [GDPR](https://eur-lex.europa.eu/eli/reg/2016/679/oj), [LOPDGDD](https://www.boe.es/buscar/act.php?id=BOE-A-2018-16673), [Commission transparency guidance](https://digital-strategy.ec.europa.eu/en/policies/guidelines-ai-transparency-obligations), [AI Act education guidance](https://ai-act-service-desk.ec.europa.eu/de/node/463), [AI literacy](https://ai-act-service-desk.ec.europa.eu/en/ai-act/article-4) and [AEPD cookie guidance](https://www.aepd.es/guias/guia-cookies.pdf). No conformity certificate or legal opinion is asserted.

## Design and verification

Direction: **The page is the object**, seed `614116899`, with no redraws. The curriculum-to-reviewed-draft workflow becomes a set of editorial folios; a local selector switches between real Notes, Exams and Programmes screenshots. All four screenshot assets come from isolated fictional/public-reference fixtures, not learner or customer records. The design uses green-black/bone/jade, self-hosted EB Garamond and Figtree and reduced-motion fallbacks. Font licences are included beside the assets. No stock photography, endorsements or adoption metrics are invented.

Browser inspection covers 1440, 768 and 390 pixel layouts, headline wrapping, local font/image loading, content overflow, the workflow selector and legal navigation. Record the final measured results and screenshots in the deployment receipt. The source lint ran with zero findings. The design script's custom browser driver is not used where the session requires browser control through CUA; equivalent DOM measurements and screenshots use the documented browser tools.
